# analysis_fav_trainers
Выгрузка реальной истории посещений клиентов одной из самых популярных студий фитнеса в Москве. Благодаря работе с данными для каждого клиента, посетившего студию в определенный отрезок времени был выявлен ее любимый тренер по количеству посещений, что помогло бизнесу более точечно взаимодействовать с пользователем по его предпочтениям.
В Excel была проведена чистка и сортировка данных, в Python была написана программа, позволяющая просчитать любимого тренера для большого объема данных.
